# profile-3d-contrib

Static SVGs for the profile README. GitHub Actions is off on this account, so they are generated by hand.

Regenerate (from the repo root):

```sh
git clone --depth 1 https://github.com/yoshi389111/github-profile-3d-contrib /tmp/3d
GITHUB_TOKEN=$(gh auth token) MAX_REPOS=100 node /tmp/3d/dist/index.js Brandon-35
```

Keep `profile-night-rainbow.svg` (dark) and `profile-green.svg` (light); delete the other files it writes.
